MAP OPTIONS

Lighting bake

Choose how much of KCD1 Map to prepare for indirect lighting.

Optional lighting bake

Baking converts static surfaces into data the engine can use for indirect light. It happens during setup, before installation. It does not remove buildings or trees, and it is separate from the shader cache the game creates while playing.

Completed lighting and native shaders are cached in your build folder and reused when their inputs and options match. Changing the bake option selects a separate cache.

Select a dated build folder containing job.json and its completed package. You will be asked before using imported outputs without matching input metadata.

Buildings and All (Forest) are experimental. Setup checks every generated tile before packaging. Native lighting parity is not established, and a full build can be lengthy. Space figures are planning allowances; duration depends on your CPU, GPU and scene complexity. Dense tiles use OptiX when supported; smaller tiles and GPU fallbacks use two CPU workers.

OPTIONAL

Opening movie

Convert the original KCD1 opening for playback in KCD2.

KCD1 opening movie

Converts the complete original movie with English audio and subtitles, then installs it with KCD1 Map. Preserves the source resolution and frame rate; this is not an AI upscale. Allow an additional 10 GiB of working space.

This replaces the shared New Game intro, including the intro shown by the ordinary KCD2 New Game option. Later campaign scenes are not included.

Setup checks for RAD Video Tools. If it is not found, select its executable in the file dialog. FFmpeg and FFprobe must also be installed and on PATH; setup checks them before building.
