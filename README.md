# KingdomComeGlueMapper website

Static documentation landing page for GitHub Pages, hosted from the root of the
`gh-pages` branch. The converter and its documentation live on `main`.

The site consists of `index.html`, `styles.css`, an original `favicon.svg` and
user-supplied gameplay screenshots under `assets/`.
It needs no JavaScript, dependencies, build pipeline, analytics or game archives.
`.nojekyll` enables direct static-file serving.

Detailed tutorials, feature evidence and release notes link to the canonical
repository documents. Keep the site's release and reviewed-source labels
separate when updating them; do not imply a source change is in a published EXE.

Before publishing, check local navigation and external links, keyboard focus,
desktop and mobile layouts, and release/recipe facts. After pushing this branch,
verify the GitHub Pages build and public content separately.
